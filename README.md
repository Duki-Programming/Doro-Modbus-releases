# Doro Modbus Beta

A Windows Modbus RTU Master / Slave simulator by Duki Programming.

- [Website / 소개](https://duki-programming.github.io/doro-modbus/)
- [English](https://duki-programming.github.io/doro-modbus/en/)
- [Beta downloads](https://github.com/Duki-Programming/Doro-Modbus-releases/releases)

Download the Windows x64 portable EXE from Releases. Python is not required.
The current beta is unsigned. SHA256SUMS.txt is provided with every release.

Features include FC01/02/03/04/05/06/15/16, CSV address lists, register decoding,
simulated Slave values, graphs, and Windows/WSL serial access. Modbus TCP is not included.

This repository contains release binaries only. Application source is maintained privately.
