## Version 1.0.0

Doro Modbus 1.0.0 is a stable release. One Windows x64 portable EXE includes Master, Slave Simulator and Simple Slave. Master supports multiple serial ports, per-port graphs and enlarged live tables.

- [Doro Modbus 1.0.0](https://github.com/Duki-Programming/Doro-Modbus-releases/releases/download/v1.0.0/Doro.Modbus.1.0.0.exe)
- [Modbus Monitor 1.0.0](https://github.com/Duki-Programming/Doro-Modbus-releases/releases/download/v1.0.0/Modbus.Monitor.1.0.0.exe)
- [SHA256 checksums](https://github.com/Duki-Programming/Doro-Modbus-releases/releases/download/v1.0.0/SHA256SUMS.txt)

Python is not required. These portable builds are unsigned.

Features include FC01/02/03/04/05/06/15/16, CSV address lists and named settings, register decoding, simulated Slave values, graphs, and Windows/WSL serial access. Imported CSV filenames become saved setting names. Modbus TCP is not included.

This repository contains release binaries only. Application source is maintained privately.
